📖 About

Python Digital Clock is a lightweight desktop application that displays the current time and date in real-time. Built entirely with Python's standard library (Tkinter), it requires no external dependencies and works seamlessly across Windows, macOS, and Linux.

The application features a modern dark theme with bright green digits, reminiscent of classic digital clocks, making it both functional and aesthetically pleasing.

Features

Real-time Display- Updates every second with precise time
Date Integration - Shows current day, month, and year
Modern Design - Sleek black background with vibrant green digits
Blinking Effect - Seconds subtly change shade for visual feedback
Fullscreen Mode - Press `F11` for immersive display
Keyboard Shortcuts - Quick exit and fullscreen toggle
12/24 Hour Format - Switch between time formats
Lightweight - Zero external dependencies
Cross-platform - Works on Windows, macOS, and Linux
Low Resource Usage - Minimal CPU and memory footprint
